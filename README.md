# 🎓 AcadBot – Academic FAQ Chatbot System

An AI-powered Academic FAQ Chatbot System developed as a Final Year Capstone Project. This platform helps students access academic information instantly while allowing administrators and class representatives to manage announcements, exams, assignments, events, and student records efficiently.

---

# 🚀 Features

## 👨‍💼 Admin Module
- Manage announcements
- Add and update exam schedules
- Add assignments and deadlines
- Manage academic events
- Upload student data using CSV
- View analytics dashboard
- Approve/reject CR announcements
- Manage student matrix and rankings

## 👥 CR (Class Representative) Module
- Create announcements
- Send announcements for admin approval
- Track approval status

## 🎓 Student Module
- View announcements
- View assignments and exam schedules
- Access personal academic matrix
- View attendance and performance
- AI chatbot for academic FAQs
- Student profile dashboard

---

# 🤖 AI Chatbot Features

The chatbot can answer:
- Exam schedules
- Assignment deadlines
- Attendance details
- Fee status
- Student rank and CGPA
- Academic announcements
- Upcoming events

### AI Support
- Google Gemini API integration
- Local NLP fallback support
